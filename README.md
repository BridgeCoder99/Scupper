Scupper Analysis for Bridge Structures

This is a rewrite (clone) of the original program used by the South Carolina
Department of Transportation to determine drainage spread on highway bridges.  
This program is unique in that it calculates drainage through circular drains 
and not the square/rectangular drains that most spreadsheets use to approximate
the spread.

Just to be clear; this program was rewritten, from scratch, using the theories
and derived equations written in the program manual.  I do not have the original
FORTRAN code and I did not reverse engineer the original executable.

Disclaimer

The Scupper program is a tool to be used by hydraulic engineers who have been 
trained in the hydraulics associated with bridges and should not be used by a
novice or inexperienced user.  Users are charged with using good engineering 
judgement in the use of this program.  The author does not provide any wanranty
